# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

Node.js must be on PATH — if `node` is not found, prefix commands with `export PATH="/opt/homebrew/bin:$PATH" &&`.

```bash
# Start development server (choose one)
npx expo start          # QR code for Expo Go on phone
npx expo start --web    # Open in browser at localhost:8081
npx expo start --ios    # iOS simulator
npx expo start --android

# Type checking
npx tsc --noEmit

# Install new dependency (always use expo install, not npm install, for native packages)
npx expo install <package>
```

There is no test suite configured.

## Architecture

This is an **Expo Router** app (file-based routing via the `app/` directory). `index.ts` is just `import 'expo-router/entry'` — the real entry is `app/_layout.tsx`.

### Data flow

1. User types a search query and selects filters in `app/index.tsx`
2. `useProductSearch` (`hooks/useProductSearch.ts`) fetches from the **Open Food Facts API** (`world.openfoodfacts.org/cgi/search.pl`), aborts in-flight requests on new searches
3. Raw API responses are converted to `Product` objects by `parseProduct` in `utils/scoring.ts`
4. `scoreAndSort` normalises numeric nutrient values across the result set (min-max scaling), computes a weighted score per active filter, filters out gluten products when `glutenFree` is active, and generates a plain-text explanation for the top-ranked product
5. Results are stored in `useProductSearch` state and rendered as a `FlatList` of `ProductCard` components
6. Tapping a card navigates to `app/product/[id].tsx`, passing the full product JSON and top-5 products as route params (serialised with `JSON.stringify`)

### Key types

- `FilterKey` (`constants/filters.ts`): `'calories' | 'protein' | 'carbs' | 'glutenFree'`
- `Product` (`utils/scoring.ts`): the normalised product shape used throughout the UI; `score` and `explanation` are populated by `scoreAndSort`
- `RawProduct`: the Open Food Facts API shape, only used inside `scoring.ts`

### Scoring logic (`utils/scoring.ts`)

- Numeric filters (`calories`, `protein`, `carbs`) use min-max normalisation across the current result set; `glutenFree` is a binary exclude filter applied first
- Scores are averaged across active numeric filters (0–1 range each)
- The explanation string is generated by comparing the top product's values against the average of all results

### Adding a new filter

1. Add an entry to `FILTERS` in `constants/filters.ts` with a new `FilterKey`
2. Add the corresponding field to the `Product` interface and populate it in `parseProduct`
3. Add a scoring branch in the `scored = filtered.map(...)` block in `scoreAndSort`
4. Add a comparison branch in `generateExplanation`
